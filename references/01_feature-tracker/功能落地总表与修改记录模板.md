# 团队管理软件功能落地总表与修改记录

> 本文档用于持续记录“团队管理软件 / 团队项目管理平台”的功能完成情况、缺口、每次修改内容、验证结果和下一步计划。  
> 每次 Codex、TRAE 或人工修改后，必须同步更新本文档。  
> 建议存放位置：`references/feature-tracker/功能落地总表与修改记录.md`

## 0. 文档维护规则

### 0.1 每次修改后必须更新

每次改动后，至少补充以下内容：

1. 修改日期与操作者；
2. 修改目标；
3. 修改文件；
4. 涉及模块；
5. 是否改变接口字段；
6. 是否改变权限规则；
7. 是否影响已有演示数据；
8. 执行了哪些验证命令；
9. 截图验收了哪些页面；
10. 新增问题；
11. 剩余问题；
12. 下一步建议。

### 0.2 状态标记

| 状态 | 含义 |
|---|---|
| 已完成 | 后端、前端、数据、权限、验证基本闭环 |
| 部分完成 | 有模型/接口/页面之一或部分流程可用，但未闭环 |
| 仅预留 | 有菜单、依赖、占位字段或文档设想，但不能作为已完成 |
| 未开始 | 尚未实现 |
| 需复核 | 已实现但未经过截图、API、权限或数据验证 |
| 暂缓 | 当前阶段不建议做 |

### 0.3 优先级标记

| 优先级 | 含义 |
|---|---|
| P0 | 不修无法演示或核心流程不可用 |
| P1 | 影响主要演示链路或业务闭环 |
| P2 | 影响完整度、体验或真实使用 |
| P3 | 美化、增强、低风险优化 |
| P4 | 远期规划 |
