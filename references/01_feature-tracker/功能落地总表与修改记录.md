## 5.1 未来需求规划（2026-07-03 新增）

> 以下四个需求由用户提出，作为 v1.1 / v1.2 阶段的重点方向，暂不在当前 v0.8.x 演示版中实现。

### 需求 A：移动端智能跳转（v1.1.0-mobile-smart）

**目标**：移动端主页的展示卡片/图表可点击，直接跳转到对应功能页面。

**具体要求**：

1. Dashboard 移动端的统计卡片（任务数、经费、项目数等）支持点击跳转：
   - 点击"任务数"卡片 → 跳转任务列表
   - 点击"经费"卡片 → 跳转经费总览
   - 点击"项目数"卡片 → 跳转项目列表
   - 点击"风险预警"卡片 → 跳转风险详情
2. Dashboard 的比赛节点日历条目支持点击跳转到比赛详情
3. 通知列表条目支持点击跳转到关联业务页面（如经费通知→经费详情）
4. 移动端底部导航栏增加"快捷操作"入口，可快速创建任务、提交贡献

**技术方向**：

- 前端：为移动端 Dashboard 卡片增加 `@click` 路由跳转，使用 `router.push()`
- 移动端增加快捷操作浮动按钮（FAB），类似微信浮窗
- 通知中心增加 `action_url` 字段，前端根据此字段跳转

### 需求 B：任务全流程移动端操作（v1.1.0-mobile-smart）

**目标**：发送、接收、处理任务等核心操作在手机端完整可用，不只是查看。

**具体要求**：

1. 移动端可创建任务（标题、描述、指派给、截止日期、优先级）
2. 移动端可修改任务状态（待办→进行中→已完成→已逾期）
3. 移动端可查看任务详情、附件、评论
4. 移动端可接收任务通知并快速操作（接受/拒绝/完成）
5. 移动端可查看任务看板（简化版，支持拖拽或按钮切换状态）

**技术方向**：

- 前端：移动端新增 `MobileTaskCreateView.vue` / `MobileTaskDetailView.vue`
- 移动端任务看板用横向滑动卡片替代 PC 端拖拽
- 后端 API 无需修改，复用现有 `/api/v1/tasks/` 接口
- 通知推送中携带 `task_id`，点击直接打开任务详情

### 需求 C：账户级个人化配置（v1.2.0-personalization）

**目标**：每个账户可自定义主页样式和布局，配置跟随账户跨设备同步，不同账户在同一设备各有独立配置。

**具体要求**：

1. 用户可自定义 Dashboard 卡片布局（拖拽排序、显示/隐藏卡片）
2. 用户可选择主题色调（从预设主题中选择，如科技蓝、暖橙、墨绿）
3. 用户可设置默认着陆页（登录后先看项目/任务/经费/Dashboard）
4. 用户可配置侧边栏菜单的折叠/展开状态和顺序
5. 用户可设置表格默认每页显示条数、默认筛选条件
6. 配置跟随账户：账户 A 在电脑 1 上修改配置后，在电脑 2 上登录同一账户也保持 A 的配置
7. 账户隔离：账户 A 和账户 B 在同一台电脑上登录时，各有各的配置，互不影响

**技术方向**：

**后端**：

- 新增 `UserPreference` 模型，存储用户个性化配置（JSON 格式）：
  ```python
  class UserPreference(models.Model):
      user = OneToOneField(User, on_delete=CASCADE)
      dashboard_layout = JSONField(default=dict)  # 卡片布局
      theme = CharField(max_length=32, default='tech_blue')
      landing_page = CharField(max_length=64, default='dashboard')
      sidebar_collapsed = BooleanField(default=False)
      sidebar_order = JSONField(default=list)
      page_size = IntegerField(default=20)
      default_filters = JSONField(default=dict)
      updated_at = DateTimeField(auto_now=True)
  ```
- 新增 API：`GET/PUT /api/v1/users/me/preferences/`
- 登录响应中附带 `preferences` 字段，前端初始化时直接应用

**前端**：

- 新增 `useUserPreferences` composable，全局管理用户配置
- Dashboard 增加"编辑布局"模式，支持拖拽排序卡片
- 主题切换使用 CSS 变量动态注入，不重新加载页面
- 侧边栏顺序通过 `vuedraggable` 拖拽排序
- 配置变更时自动调用 `PUT /api/v1/users/me/preferences/` 保存
- 登录时从后端拉取配置并应用到全局 store
- 退出登录时清除本地缓存，避免账户间配置串扰

**关键约束**：

- 配置存储在后端，不依赖 localStorage（确保跨设备同步）
- localStorage 仅用作临时缓存，登录时以后端配置为准覆盖
- 主题色变更不能影响 Element Plus 组件的功能性样式
- 配置项必须有合理默认值，新用户开箱即用
