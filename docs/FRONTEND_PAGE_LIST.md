## 优化优先级说明

### 高优先级（建议优先优化）

影响核心演示体验与首屏观感的页面：

- **登录页**：品牌第一印象，需提升视觉品质与响应式
- **首页驾驶舱**：核心展示页，需统一图表配色与卡片层次
- **项目列表**：高频访问页，需优化卡片信息层次与加载态
- **任务列表**：核心工作台，需增加临期提醒与多视图
- **经费总览**：经费透明是核心卖点，需优化金额展示与票据预览
- **我的贡献**：高频操作页，需优化状态展示与表单体验
- **知识产权列表**：核心业务页，需语义化标签与进度提示
- **敏感资料中心**：安全场景核心页，需强化安全视觉与脱敏样式

### 中优先级（建议二期优化）

功能完整但视觉/交互有提升空间的页面：项目详情、比赛管理、人员管理、成员详情、文件管理、待我审核、知识产权详情、知识产权待办、查看申请、待我审批、通知中心、操作日志、用户管理。

### 低优先级（可后续迭代）

使用频率较低或功能较简单的页面：导入中心、我的灵活工时、团队灵活工时、技能标签、我的资料、第三方集成。

## 全局设计优化建议

### 配色体系
- 当前各页面标签配色不统一，建议建立语义化配色规范：成功（绿）、警告（橙）、危险（红）、进行中（蓝）、待处理（灰）
- 统一图表主题色，避免每个图表配色不一致

### 间距与布局
- 卡片间距建议统一为 16px/24px 两档
- 表单字段间距统一为 12px，分组间距 24px
- 列表行高统一，避免不同页面行高不一致

### 交互体验
- 全局增加骨架屏加载态，替代当前的空白闪烁
- 空状态统一使用插画+引导文案，替代纯文字提示
- 标签统一使用语义化彩色徽章

### 响应式适配
- 当前部分页面在小屏下表格溢出，建议表格在移动端转为卡片流式布局
- 图表需自适应容器宽度，避免横向滚动

### 图标体系
- 文件类型、通知类型、模块类型建议统一使用风格一致的图标集
- 关键操作按钮增加图标提示，提升识别效率

## 补充四：公共主页后续设计方向

当前系统为内部管理平台，未来如需面向外部访客的公共展示主页，建议以下设计方向：

### 展示内容

| 区域 | 内容 | 数据来源 |
|------|------|----------|
| 顶部 Banner | 团队名称、Logo、简介 | 团队信息配置 |
| 项目成果展示 | 已完成项目的成果卡片（封面+标题+简介+标签） | 项目表中状态为"已结项"的项目 |
| 比赛获奖记录 | 比赛获奖时间线 | 比赛表中获奖记录 |
| 知识产权成果 | 软著/专利/论文列表 | IP 表中已归档的申请 |
| 团队成员介绍 | 核心成员卡片（头像+姓名+角色+方向） | 用户表中 active 成员 |
| 数据统计 | 累计项目数、比赛获奖数、知识产权数 | 各模块统计聚合 |

### 设计风格建议

- 采用简洁现代的卡片式布局
- 主色调使用团队品牌色（建议蓝/绿系科技感配色）
- 成果展示增加 Hover 动效
- 支持响应式适配，移动端转为单列流式布局
- 数据统计区使用大数字+图标的设计语言
