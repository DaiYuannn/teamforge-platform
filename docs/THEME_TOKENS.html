1. 推荐主题 Token 总览

基于项目需求定制的 Team Cockpit 主题，核心设计原则：

  • 保留所有现有 SCSS 变量名和值，不删除、不重命名
  • 新增模块专属色、渐变色、扩展圆角/阴影/间距体系
  • 兼容 Element Plus，不覆盖 Element Plus 内部变量
  • 新增 CSS 变量（:root），供 Vue 组件内联引用

5. 结论

5.1 推荐设计方向

  • Team Cockpit 主题：科技蓝 #409EFF 为主色，青蓝 #36CFC9 为渐变辅色，清爽可信
  • 模块专属色体系：知识产权紫色 / 敏感资料安全蓝 / 经费深绿，视觉区分模块属性
  • 保留 Element Plus 原生体系：不覆盖 Element Plus 内部 SCSS 变量，仅通过 CSS 变量层扩展
  • 渐进式增强：先写 token，再逐批应用，每批验证

5.2 不推荐的设计方向

  • 不使用 10 个预设主题中的任何一个：它们都是面向幻灯片/文档的通用主题，缺少模块专属色
  • 不覆盖 Element Plus 内部变量：不修改 node_modules/element-plus 主题文件
  • 不引入 CSS-in-JS：保持 SCSS + CSS 变量方式
  • 不引入 Tailwind：不为 P3 美化引入新 CSS 框架
